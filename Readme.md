# 図形融合したいプラグイン v0.2.0
> [!IMPORTANT]
> - なお本プラグインの制作にはClaudeが使用されております｡人間によるテストは行っておりますが､一部確認不足が存在する可能性があります｡

## 概要:
2つの円を接近度合いに応じて滑らかなベジェ曲線で接続する図形プラグインです｡  
円1・円2それぞれの位置(X, Y)・半径、および接続割合(0〜100%)をタイムラインのアイテム設定パネルから調整できます｡  
接続割合を上げるほど2つの円がより一体化した見た目になります｡  

## 使い方:
#### 「円融合」
	1. 図形アイテムを追加し､種類から「図形融合プラグイン:円」を選択
	2. [円1]/[円2]グループのX・Y・半径で2つの円を配置
	3. [接続]グループの接続割合で繋ぎ目の太さ・一体感を調整
#### 「動的融合」
	1. 2つ図形アイテムを追加し､映像エフェクトから「動的融合:対象」を選択
	2. 図形アイテムを追加し､種類を「背景」に､色を透明に設定
	3. 「背景」アイテムに映像エフェクトから「動的融合:制御」を追加

## その他:
- AviUtl拡張編集(.exo)形式への出力には対応していません｡
- 円が重なる・片方の半径が極端に大きい等の境界条件は簡易的なものです｡
- 作者は､本プラグインの使用または使用不能に起因するいかなる損害についても､一切の責任を負いません｡
- Windows11 Home(64bit)､ゆっくりMovieMaker4 : v4.56.1.0にて動作確認をしています｡

## インストール:
1. [Releases](https://github.com/kikaisya-tdd/YMM4_shape-fusion-plugin/releases)から`shape-fusion-plugin.x.x.x.ymme`をダウンロード
2. ファイルをYMM4のウィンドウにドラッグ&ドロップ 又は ダウンロードされた.ymmeファイルをダブルクリック
3. YMM4を再起動  
又は  
1. YMM4のプラグインポータルツールから追加
